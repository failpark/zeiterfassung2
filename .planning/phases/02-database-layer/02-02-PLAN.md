   - Rewrite `run_migrations` function: remove async, remove Rocket types. Make it a sync function that takes `&mut MysqlConnection`:
     ```rust
     use diesel_migrations::{embed_migrations, EmbeddedMigrations, MigrationHarness};
     pub const MIGRATIONS: EmbeddedMigrations = embed_migrations!("../migrations");

     pub fn run_migrations(conn: &mut MysqlConnection) {
         conn.run_pending_migrations(MIGRATIONS)
             .expect("Failed to run database migrations");
         ::tracing::info!("Database migrations applied successfully");
     }
     ```
     Note: Use `::tracing::` prefix since the project has a `tracing` module that shadows the crate name.

3. For EACH of user.rs, client.rs, activity.rs, project.rs — apply the SAME mechanical transformation:
   a. Replace `use rocket_db_pools::{diesel::{insert_into, prelude::*}, Connection};` with:
      ```rust
      use diesel::prelude::*;
      use diesel::{insert_into, MysqlConnection};
      ```
      Note: `insert_into` comes from `diesel::` directly, NOT `diesel::prelude`. Check if `diesel::prelude::*` re-exports it. If it does, just use `use diesel::prelude::*;` and `use diesel::MysqlConnection;`.
   b. Replace `use rocket_db_pools::diesel::RunQueryDsl;` if present — it is already in `diesel::prelude::*`
   c. Remove `use crate::DB;` — DB struct no longer exists
   d. Change ALL function signatures from `async fn name(db: &mut Connection<DB>, ...)` to `fn name(db: &mut MysqlConnection, ...)`
   e. Remove ALL `.await` from diesel query calls (`.first::<Self>(db).await` becomes `.first::<Self>(db)`)
   f. Remove `Box::pin(async move { ... })` wrappers from transactions. Change:
      ```rust
      db.transaction(|mut conn| {
          Box::pin(async move {
              insert_into(table).values(item).execute(&mut conn).await?;
              table.filter(id.eq(last_insert_id())).first::<Self>(&mut conn).await
          })
      }).await
      ```
      to:
      ```rust
      db.transaction(|conn| {
          insert_into(table).values(item).execute(conn)?;
          table.select(Self::as_select()).filter(id.eq(last_insert_id())).first::<Self>(conn)
      })
      ```
      Note: In sync transactions the closure param is `conn: &mut MysqlConnection` (no `mut conn` binding needed since it is already `&mut`).
   g. For user.rs specifically: `check_credentials` also becomes sync. Remove `async` keyword and all `.await`.
