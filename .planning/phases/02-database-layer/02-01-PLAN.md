     e. Log with password redacted: `tracing::info!(pool_size = 10, connection = %redact_password(&database_url), "Database pool initialized");`
   - Add `redact_password` helper function (private to the binary):
     ```rust
     fn redact_password(url: &str) -> String {
         if let Some(at_pos) = url.find('@') {
             if let Some(colon_pos) = url[..at_pos].rfind(':') {
                 let mut redacted = url.to_string();
                 redacted.replace_range((colon_pos + 1)..at_pos, "***");
                 return redacted;
             }
         }
         url.to_string()
     }
     ```
   - Update AppState construction to include `db_pool`: `let state = AppState { config: Arc::new(config), db_pool };`
