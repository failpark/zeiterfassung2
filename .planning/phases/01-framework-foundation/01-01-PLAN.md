- Keep the `Error` enum with thiserror but remove all Rocket-specific variants (RocketCors, Rocket).

- Keep `pub type Result<T> = std::result::Result<T, Error>`.

**lib.rs** — Rewrite completely:
- Declare modules: `pub mod config;`, `pub mod state;`, `pub mod error;`, `pub mod tracing;`, `mod routes;`.
- Comment out modules not yet ported: `// mod auth;`, `// mod catchers;`, `// mod db;`, `// mod guard;`, `// mod schema;`. Add TODO comments.
- Keep `#[cfg(test)] mod test;` commented out too (tests use Rocket).
- Create `pub fn app(state: AppState) -> Router` function:
  - Build `cors_layer` using a helper fn `fn cors_layer(config: &AppConfig) -> CorsLayer`:
    - If `config.is_development()`: use `AllowOrigin::mirror_request()` (NOT `Any` — see CORS pitfall in research).
    - Else: `AllowOrigin::list(config.cors.allowed_origins.iter().map(|o| o.parse::<HeaderValue>().expect("invalid CORS origin")))`.
    - Methods: GET, POST, PUT, DELETE, OPTIONS.
    - Headers: AUTHORIZATION, CONTENT_TYPE, ACCEPT.
    - `allow_credentials(true)`.
    - `max_age`: 0 seconds in dev, 600 seconds in prod.
  - Build middleware stack with `ServiceBuilder::new()`:
    1. `.layer(SetRequestIdLayer::x_request_id(MakeRequestUuid))` — request ID set first
    2. `.layer(TraceLayer::new_for_http().make_span_with(...).on_response(...))` — tracing second, so span includes request_id
    3. `.layer(cors)` — CORS third
    4. `.layer(PropagateRequestIdLayer::x_request_id())` — propagate ID to response last
  - TraceLayer make_span_with: extract x-request-id from headers, create `info_span!("http_request", method, uri, request_id)`.
  - TraceLayer on_response: use `DefaultOnResponse::new().level(Level::INFO)` to log status and duration.
  - Build public router: `Router::new().route("/health", get(routes::health::health))`.
  - For now, no protected router (that's Plan 02).
  - Assemble: `Router::new().merge(public).layer(middleware_stack).with_state(state)`.
- Re-export: `pub use error::{Error, Result};` and `pub use state::AppState;`.
