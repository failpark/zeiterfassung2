**middleware/mod.rs** — Create new directory and file:
- `pub mod auth;`

**middleware/auth.rs** — Create new file:
- Implement `pub async fn require_auth(request: Request, next: Next) -> Result<Response, AppError>`:
  - Extract `Authorization` header from request.
  - If missing or doesn't start with "Bearer ": return `Err(AppError::Unauthorized)` (which produces 401 JSON via IntoResponse).
  - Extract token after "Bearer " prefix, trim whitespace.
  - If token is empty: return `Err(AppError::Unauthorized)`.
  - Phase 1: presence check only. Add comment: `// TODO(Phase 3): Validate JWT token and extract claims`.
  - Call `Ok(next.run(request).await)`.
- Imports: `axum::extract::Request`, `axum::middleware::Next`, `axum::response::Response`, and the app Error type.
- NOTE: Use `AppError` (or whatever the error type is named from error.rs). The auth middleware returns the app error type so it produces {code, message, details} JSON — NOT bare `StatusCode::UNAUTHORIZED`.

**routes/ping.rs** — Create new file:
- `pub async fn ping() -> &'static str { "pong" }`
- This is a minimal protected test endpoint to verify auth middleware works.

**routes/mod.rs** — Update:
- Add `pub mod ping;` alongside existing `pub mod health;`.

**lib.rs** — Update the `app()` function:
- Add `mod middleware;` declaration.
- Split router into public and protected:
  ```
  let public = Router::new()
      .route("/health", get(routes::health::health));

  let protected = Router::new()
      .route("/api/ping", get(routes::ping::ping))
      .route_layer(axum::middleware::from_fn(middleware::auth::require_auth));
  ```
- IMPORTANT: Use `route_layer` (NOT `layer`) on protected router — `route_layer` only runs when a route matches, so unknown paths still get 404 instead of 401.
- Merge both: `Router::new().merge(public).merge(protected).layer(middleware_stack).with_state(state)`.
- If require_auth needs AppState (it shouldn't in Phase 1, but if the error type requires it), use `from_fn_with_state(state.clone(), ...)`.

**Pattern for Axum integration tests:**
```rust
use axum::body::Body;
use axum::http::{Request, StatusCode};
use tower::ServiceExt; // for oneshot
use zeiterfassung_backend::{app, AppState, config::AppConfig};

fn test_state() -> AppState {
    // Create minimal AppConfig for testing
    AppState { config: std::sync::Arc::new(test_config()) }
}

#[tokio::test]
async fn health_returns_200() {
    let app = app(test_state());
    let response = app
        .oneshot(Request::builder().uri("/health").body(Body::empty()).unwrap())
        .await
        .unwrap();
    assert_eq!(response.status(), StatusCode::OK);
}
```

Make sure `app()` and `AppState` are publicly exported from lib.rs for integration tests to use. Also ensure `AppConfig` can be constructed in tests — either make fields public or add a `AppConfig::default()` / test constructor.
