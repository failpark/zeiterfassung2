Implement `login` handler:
```rust
pub async fn login(
    State(state): State<AppState>,
    Json(req): Json<LoginRequest>,
) -> Result<Json<LoginResponse>, Error> {
    let email = req.email;
    let password = req.password;

    let result = state
        .db_pool
        .get()
        .await?
        .interact(move |conn| {
            User::check_credentials(conn, &email, &password)
        })
        .await?;

    match result {
        Ok(user) => {
            let token = state.tokenizer.generate(user)?;
            Ok(Json(LoginResponse { token }))
        }
        Err(_) => {
            // Artificial delay on ALL failures — prevents user enumeration
            // (same delay for unknown-email and wrong-password)
            tokio::time::sleep(std::time::Duration::from_millis(500)).await;
            Err(Error::WrongCredentials)
        }
    }
}
```

Important details:
- Use `State<AppState>` extractor (not `State<Arc<AppState>>`)
- The `interact()` closure receives `&mut MysqlConnection` — call `User::check_credentials(conn, &email, &password)` which returns `Result<User>`
- The outer `.await?` handles `InteractError` (already has `From` impl to `Error::Internal`)
- The inner `result` is `Result<User, Error>` — match on it
- On success: `state.tokenizer.generate(user)?` returns `Result<String>`
- On failure: `tokio::time::sleep(500ms)` then return `Err(Error::WrongCredentials)`

Implement `logout` handler:
```rust

    // Stub — client discards token; endpoint exists for future server-side blacklisting
    StatusCode::OK
}
```
