**2. Create `backend/src/auth/extractor.rs`:**

Implement two extractors following the pattern from research:

`AuthUser(pub User)` — `FromRequestParts` impl:
- Bound: `where AppState: FromRef<S>, S: Send + Sync`
- Extract `State<AppState>` to get tokenizer
- Extract `TypedHeader<Authorization<Bearer>>` for the token (use `axum_extra::headers::{authorization::Bearer, Authorization}` and `axum_extra::TypedHeader`)
- Call `state.tokenizer.verify(bearer.token())` — returns `Result<User>`
- Map TypedHeader extraction failure to `Error::Unauthorized`
- Rejection type: `Error`

`AdminUser(pub User)` — `FromRequestParts` impl:
- Delegates to `AuthUser::from_request_parts(parts, state).await?`
- Checks `user.sys_role == Role::Admin` — if not, returns `Err(Error::ForbiddenAccess)`
- Rejection type: `Error`

Use `axum::extract::FromRef` for the state bound.

**3. Update `backend/src/auth/mod.rs`:**
